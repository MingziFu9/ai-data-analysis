# 证书考点对照

本页列出本课程对应的三个职业技能证书，以及每个考核模块在本书中的位置。正文中带“证书考点”提示框的小节，就是下表列出的考点。

## 对应证书

| 证书 | 级别 | 发证机构 | 考核依据 | 考核形式 |
|---|---|---|---|---|
| 人工智能训练师 | 四级 / 中级工 | 人力资源和社会保障部、工业和信息化部（职业技能等级认定） | 《人工智能训练师国家职业技能标准》（2021 年版，职业编码 4-04-05-05） | 理论知识考试和技能考核，均实行百分制，均达 60 分及以上为合格 |
| 人工智能数据处理工程师 | 中级 | 工业和信息化部教育与考试中心 | 《人工智能数据处理工程师》培训课程标准（试行版，2022 年 12 月） | 理论与实操 |
| Python 技术应用工程师 | 中级 | 工业和信息化部教育与考试中心 | 未找到官方考纲，依据培训机构公开的报考说明 | 上机考试，题型为单选、多选、判断、实操、简答 |
