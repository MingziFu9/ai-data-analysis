## A.1 运行第一个程序

### A.1.1 三种运行方式

Python 程序就是一个写满指令的文本文件，扩展名是 `.py`。运行它有三种常用方式：

| 方式 | 怎么做 | 适合 |
|---|---|---|
| Jupyter | 在命令行窗口运行 `jupyter lab`，浏览器里新建 Notebook，在格子里写代码，按 **Shift + Enter** 运行 | 初学、边试边看结果（推荐） |
| 运行 `.py` 文件 | 在命令行窗口进入文件所在的文件夹，运行 `python 文件名.py` | 运行本书的实验程序 |
| 交互模式 | 在命令行窗口输入 `python` 回车，出现 `>>>` 后一行一行输入；输入 `exit()` 退出 | 临时算一下 |

本书的实验程序都是 `.py` 文件，你可以直接运行它，也可以把里面的代码分段复制到 Jupyter 的格子里运行。

### A.1.2 print 和注释

在 Jupyter 的格子里输入下面的代码并运行：

```python
print("你好，食客说！")        # 在屏幕上显示一行文字
print(1 + 2)                   # 也可以显示计算结果
# 以 # 开头的是注释，Python 会跳过它，它是写给人看的说明
```

运行结果：

```text
你好，食客说！
3
```

`print()` 是最常用的命令，括号里放什么，屏幕上就显示什么。文字要用引号括起来，数字和算式不用。本书代码里大量的中文注释，就是帮你读懂每一行在做什么的。

**三条规则一定要记住：**

1. 代码里的括号、引号、逗号、冒号**都要用英文半角**。`print（"你好"）` 用了中文括号，会报错。
2. Python **区分大小写**，`print` 不能写成 `Print`。
3. Python 用**缩进**（行首的空格）表示代码的层次，不能随便加空格。缩进的规矩在 A.6 节讲。

## A.2 变量和数据类型

### A.2.1 变量：给数据起个名字

**变量**就像贴了标签的盒子，用 `=` 把数据放进去，以后用名字就能取出来。这里的 `=` 不是“等于”，而是“把右边的值放进左边的名字里”。

```python
price = 84               # 人均价格
people = 3               # 就餐人数
total = price * people   # 用变量计算
print(total)
price = 90               # 重新赋值，盒子里的东西被换掉
print(price)
```

运行结果：

```text
252
90
```

变量名可以用中文、英文字母、数字和下划线，但不能以数字开头，不能有空格。本书习惯用有意义的英文名，比如 `price`、`orders`，也会用中文名，比如 `人均价格`。

### A.2.2 四种基本数据类型

| 类型 | 名称 | 例子 | 说明 |
|---|---|---|---|
| `int` | 整数 | `3`、`-5`、`56655` | 没有小数点 |
| `float` | 小数（浮点数） | `84.5`、`0.25` | 有小数点 |
| `str` | 字符串（文字） | `"粤菜"`、`'天河'` | 用引号括起来，单引号、双引号都行 |
| `bool` | 布尔值（真假） | `True`、`False` | 只有两个值，首字母大写 |

用 `type()` 可以查看一个值是什么类型：

```python
print(type(84), type(84.5), type("84"), type(True))
```

运行结果：

```text
<class 'int'> <class 'float'> <class 'str'> <class 'bool'>
```

注意 `84` 和 `"84"` 是不一样的：前者是数字，能做加减乘除；后者是文字，只是长得像数字。从文件里读进来的数据有时会“看起来是数字，其实是文字”，这是第 4 章清洗数据时常遇到的问题。

### A.2.3 算术运算和类型转换

```python
print(7 + 2, 7 - 2, 7 * 2, 7 / 2)    # 加、减、乘、除
print(7 // 2, 7 % 2, 7 ** 2)         # 整除、取余数、乘方
print(round(3.14159, 2))             # 四舍五入保留 2 位小数
print(int("84") + 1, float("84.5"), str(84) + "元")   # 类型转换
```

运行结果：

```text
9 5 14 3.5
3 1 49
3.14
85 84.5 84元
```

`int()`、`float()`、`str()` 分别把值转换成整数、小数和字符串。`"84" + 1` 会报错，因为文字和数字不能直接相加，要先用 `int("84")` 把文字变成数字。

## A.3 字符串

数据分析经常要处理文字：店名、评论、地址。处理文字用的就是字符串。

### A.3.1 拼接和格式化

```python
name = "好味粤菜"
district = "番禺"
print(name + "（" + district + "店）")          # 用 + 拼接
score = 4.567
print(f"{name}的平均评分是 {score:.1f} 分")       # f 字符串：把变量放进 {} 里
print(f"好评率 {0.6382:.1%}")                    # .1% 表示百分数、保留 1 位小数
```

运行结果：

```text
好味粤菜（番禺店）
好味粤菜的平均评分是 4.6 分
好评率 63.8%
```

在引号前面加一个 `f`，引号里就可以用 `{变量名}` 把变量的值放进去，这叫 **f 字符串**，本书打印结果时几乎都用它。`{score:.1f}` 的意思是保留 1 位小数，`{x:.1%}` 是换算成百分数。

### A.3.2 常用操作

```python
s = "  服务很好，菜量足，就是送得慢  "
print(len(s))                  # 长度（字符数，空格也算）
s = s.strip()                  # 去掉两头的空格
print(s)
print("送得慢" in s)            # 是否包含某段文字
print(s.replace("慢", "快"))   # 替换
print(s.split("，"))           # 按中文逗号切开，得到一个列表
print(s[0:4], s[-3:])          # 切片：取前 4 个字、最后 3 个字
```

运行结果：

```text
18
服务很好，菜量足，就是送得慢
True
服务很好，菜量足，就是送得快
['服务很好', '菜量足', '就是送得慢']
服务很好 送得慢
```

**切片**的写法是 `s[开始:结束]`，位置从 0 开始数，取到“结束”的前一个为止；负数表示从后往前数，`-1` 是最后一个。`s[0:4]` 取第 0、1、2、3 个字。

## A.4 列表

### A.4.1 创建和取值

**列表**把多个值按顺序放在一起，用方括号 `[]` 表示，值之间用逗号隔开。它就像 Excel 里的一列。

```python
prices = [84, 27, 115, 82, 86]       # 5 家店的人均价格
print(prices[0], prices[-1])          # 第一个、最后一个（位置从 0 开始）
print(prices[1:3])                    # 切片：第 1、2 个
print(len(prices), sum(prices), max(prices), min(prices))
print(sum(prices) / len(prices))      # 平均值
```

运行结果：

```text

[27, 115]
5 394 115 27
78.8
```

cuisines = ["粤菜", "快餐", "火锅"]

运行结果：

## A.5 字典

**字典**存放的是“键 → 值”的对应关系，用花括号 `{}` 表示。它就像一张只有两列的对照表：通过“键”（如店铺编号）查到“值”（如店名）。

```python
shop = {"店名": "好味粤菜", "城区": "番禺", "人均价格": 84}
print(shop["店名"])                     # 按键取值
shop["人均价格"] = 90                   # 修改
shop["菜系"] = "粤菜"                   # 添加新的键值对
print(shop)
print(shop.get("电话", "未登记"))       # 取不到时返回默认值，不报错
for key, value in shop.items():         # 逐个取出键和值
    print(key, "→", value)
```

运行结果：

```text
好味粤菜
{'店名': '好味粤菜', '城区': '番禺', '人均价格': 90, '菜系': '粤菜'}
未登记
店名 → 好味粤菜
城区 → 番禺
人均价格 → 90
菜系 → 粤菜
```

直接用 `shop["电话"]` 取一个不存在的键，会报 `KeyError` 错误，`get()` 则会返回你给的默认值。

字典在本书中最常见的用途有两个：一是把规则写成对照表，比如第 4 章把各种写法统一为标准城区名 `{"天河区": "天河", "Tianhe": "天河"}`；二是读取 JSON 格式的接口数据（第 3 章），JSON 读进来就是字典和列表。

## A.6 条件判断

### A.6.1 if、elif、else

```python
minutes = 52                      # 送达时长
if minutes <= 30:
    print("准时")
elif minutes <= 45:
    print("稍慢")
else:
    print("超时")
print("判断结束")
```

运行结果：

```text
超时
判断结束
```

这段代码的读法是：如果不超过 30 分钟，打印“准时”；否则如果不超过 45 分钟，打印“稍慢”；都不是，打印“超时”。注意三个要点：

- `if`、`elif`、`else` 这一行的末尾要有**英文冒号** `:`；
- 下面属于它的代码要**缩进 4 个空格**（Jupyter 和大多数编辑器按 Tab 键会自动变成 4 个空格）；
- 缩进结束，就回到了判断外面，`print("判断结束")` 不管条件如何都会执行。

### A.6.2 比较和组合条件

| 写法 | 含义 | 写法 | 含义 |
|---|---|---|---|
| `==` | 等于（两个等号） | `!=` | 不等于 |
| `>`、`<` | 大于、小于 | `>=`、`<=` | 大于等于、小于等于 |
| `and` | 并且（两个都满足） | `or` | 或者（满足一个即可） |
| `not` | 不是 | `in` | 在……里面 |

```python
district, price = "天河", 115
print(district == "天河" and price > 100)      # 天河区并且人均超过 100
print(district in ["越秀", "荔湾"] or price < 50)
```

运行结果：

```text
True
False
```

一个等号 `=` 是赋值，两个等号 `==` 才是比较，这是初学者最常写错的地方。

## A.7 循环

### A.7.1 for 循环

**循环**让同一段代码对一批数据逐个执行。

```python
prices = [84, 27, 115, 82, 86]
for p in prices:                # 依次把每个价格放进 p，执行下面缩进的代码
    if p > 80:
        print(p, "偏贵")
```

运行结果：

```text
84 偏贵
115 偏贵
82 偏贵
86 偏贵
```

### A.7.2 累加和计数

在循环外先准备一个“计数器”，循环里不断往上加，这是最常用的写法：

```python
minutes = [17, 16, 35, 52, 28, 47]
late = 0                         # 计数器，从 0 开始
for m in minutes:
    if m > 45:
        late = late + 1          # 也可以写成 late += 1
print(f"超时 {late} 单，占 {late / len(minutes):.0%}")
for i in range(3):               # range(3) 依次给出 0、1、2
    print("第", i + 1, "次")
```

运行结果：

```text
超时 2 单，占 33%
第 1 次
第 2 次
第 3 次
```

### A.7.3 列表推导式（看懂即可）

把“循环 + 判断 + 放进新列表”写成一行，叫**列表推导式**。本书偶尔会用，看懂就行：

```python
minutes = [17, 16, 35, 52, 28, 47]
late_list = [m for m in minutes if m > 45]     # 挑出超过 45 分钟的
hours = [round(m / 60, 2) for m in minutes]    # 每个都换算成小时
print(late_list, hours)
```

运行结果：

```text
[52, 47] [0.28, 0.27, 0.58, 0.87, 0.47, 0.78]
```

**一个重要提醒：**学完第 2 章你会发现，用 pandas 处理表格时，**几乎不需要自己写循环**，整列一起算更简单、更快（2.7 节的“向量化”）。所以这里的循环只要能看懂就行。

## A.8 函数

### A.8.1 使用函数

前面用过的 `print()`、`len()`、`round()` 都是**函数**：给它输入（放在括号里，叫**参数**），它完成一件事，有的还会交回一个结果（叫**返回值**）。

```python
print(round(3.14159, 2))          # 两个参数：要处理的数、保留几位
print(sorted([3, 1, 2], reverse=True))   # reverse=True 是按名字传的参数
```

运行结果：

```text
3.14
[3, 2, 1]
```

### A.8.2 自己写函数

把一段常用的代码包装起来，起个名字，以后一行就能调用，这就是自己定义函数：

```python
def mask_phone(phone):
    """把手机号中间 4 位换成 *"""
    return phone[:3] + "****" + phone[-4:]

def level(minutes, limit=45):        # limit 有默认值，不传就用 45
    return "超时" if minutes > limit else "正常"

print(mask_phone("18545161843"))
print(level(52), level(52, limit=60))
```

运行结果：

```text
185****1843
超时 正常
```

- `def 函数名(参数):` 开头，下面缩进的是函数的内容；
- `return` 后面是交回的结果；
- 三引号里的文字是函数的说明，写给人看的；
- `"超时" if 条件 else "正常"` 是把简单的 if-else 写成一行，条件成立取前一个，否则取后一个。

第 4 章的清洗程序 `cleaning.py` 就是把一个个清洗步骤写成函数，再按顺序调用。

## A.10 读懂报错

### A.10.1 先看最后一行

程序出错时，Python 会打印一段“报错信息”（Traceback）。很多同学一看到红色的一大段就慌了，其实**只要先看最后一行**：冒号前面是错误类型，后面是原因。往上几行会标出出错的是哪个文件的第几行。

```text
Traceback (most recent call last):
  File "lab2_1.py", line 5, in <module>
    print(shop["电话"])
          ~~~~^^^^^^^^
KeyError: '电话'
```

这段的意思是：`lab2_1.py` 第 5 行出错，错误类型是 `KeyError`（键不存在），找不到的键是 `'电话'`。

### A.10.2 常见错误速查

| 错误类型 | 常见原因 | 怎么改 |
|---|---|---|
| `SyntaxError` | 语法写错：用了中文标点、括号或引号没配对、`if` 后面少冒号 | 检查出错那一行及上一行的标点 |
| `IndentationError` | 缩进不对：多了或少了空格，Tab 和空格混用 | 统一用 4 个空格；该缩进的地方缩进 |
| `NameError: name 'xx' is not defined` | 变量名拼错，或者还没定义就用了；Jupyter 里没有运行前面的格子 | 检查拼写和大小写；从头依次运行各格 |
| `TypeError` | 类型不对，比如文字和数字相加 `"3" + 2` | 用 `int()`、`str()` 转换类型 |
| `KeyError` | 字典里没有这个键；pandas 里没有这一列（多见于列名有空格或拼错） | 用 `print(df.columns)` 看看真实的列名 |
| `IndexError` | 位置超出范围，比如列表只有 5 个却取 `[5]` | 位置从 0 开始，最后一个是 `[-1]` |
| `FileNotFoundError` | 找不到文件：没在实验文件夹里运行，或文件名、路径写错 | 先 `cd` 到实验所在文件夹；核对文件名 |
| `ModuleNotFoundError: No module named 'xx'` | 库没装，或者装在了另一个环境里 | `pip install xx`；确认已经激活了本课程的环境 |
| `UnicodeDecodeError` | 文件编码不对，常见于 Excel 另存的 CSV | `pd.read_csv(文件, encoding="gbk")`，见 3.2 节 |
| `ValueError` | 值不合适，比如 `int("八十")`、日期格式不对 | 检查数据里有没有异常的值 |

**排错三步法：**① 看最后一行，判断错误类型；② 找到出错的行号，看那一行和它的上一行；③ 还看不懂，把完整的报错信息复制给大模型或老师，问“这个错误是什么意思，怎么改”。

**警告不是错误。**以 `Warning` 结尾的信息（比如画图时的 `findfont` 警告、pandas 的 `FutureWarning`）是提醒，程序仍然正常运行，结果没问题就可以先不管。

| 你在 Excel 里做的 | pandas 的写法 |
|---|---|
| 打开文件 | `pd.read_csv("文件.csv")`、`pd.read_excel("文件.xlsx")` |

## A.12 和大模型一起学 Python

文心一言、通义千问、DeepSeek、Kimi 等大模型很擅长解释代码，是零基础同学的好帮手。几种好用的问法：

| 想做什么 | 可以这样问 |
|---|---|
| 看不懂代码 | “我是 Python 初学者，请逐行解释这段代码，每行说明它做了什么：（粘贴代码）” |
| 看不懂报错 | “运行下面的代码出现了这个报错，请告诉我原因和改法：（粘贴代码和完整报错信息）” |
| 不知道怎么写 | “我有一个 pandas 表 shops，列有店名、城区、菜系、人均价格。怎样统计每个城区人均价格超过 100 元的店有几家？” |
| 想举一反三 | “这段代码换一种写法可以吗？两种写法有什么区别？” |

用大模型时要记住两点（详见实验 1-3）：

1. **它写的代码不一定对。**运行之前先读一遍，运行之后用“核对总数”“对照常识”的方法检查结果，比如各组加起来是否等于总数、平均价格是否在合理范围内。
2. **不要把真实的个人信息发给它。**提问时只描述列名和结构，或者用几行编造的例子，不要粘贴真实的用户数据（第 12 章）。
