# 人工智能数据分析与处理

**课程名称：** 人工智能数据分析与处理

**授课对象：** 成人教育（开放教育）人工智能技术应用专业专科学生，多为在职学习者，线上自学为主

**学分学时：** 4 学分，72 学时（理论 54 学时，其中线上 40、线下 14；实验 18 学时，线上），第 4 学期开设，期末开卷考试

**先修要求：** 学过“Python 程序设计”，但按 Python 初学者设计（几乎没有编程经验也能学：★ 基础实验都给完整代码，学生以读懂、运行、修改为主，附录 A 提供零基础入门）、“数据库基础与应用”（会写简单的 SELECT 查询）和“机器学习”（知道训练集、测试集、分类、回归、聚类、混淆矩阵，第 2 章做过数据预处理和特征工程）。书中用到的机器学习知识都在“先修要求”里给出链接和一段速记。

**对应证书：** 人工智能训练师（四级）（人社部、工信部国家职业技能标准 2021 年版）、人工智能数据处理工程师（中级，工信部教育与考试中心）、Python 技术应用工程师（中级）。书末单列“证书考点对照”页，正文对应小节用“证书考点”提示框标出。训练师四级的“数据标注”在理论考试中占 40%、技能考试中占 50%，本课用两章来讲。

## 课程概述

人工智能模型的好坏，七分在数据。一个外卖平台要训练评论情感分析模型，先要把散落在订单库、点评接口、客服记录里的数据采集下来，清洗干净，再请标注员按统一规范给每条评论打上“好评”“差评”，审核标注质量，然后才轮得到建模；模型上线以后，还要有人盯着它的表现，发现新出现的错误，整理成优化需求交给算法工程师。这一整条链上的工作，就是人工智能训练师、数据处理工程师每天在做的事，也是本课程要教会学生的事。

本课程坚持“会用为主、原理够用”。全书按一份数据在人工智能项目中走过的路组织：先在 NumPy、pandas 上把数据处理的基本功练扎实，再学数据采集、数据清洗、数据标注与质量审核、探索性分析与统计检验、可视化与分析报告；然后用 scikit-learn 和现成的预训练模型对数据建模，做一个推荐系统；最后学习智能系统上线后的运维与优化，以及数据处理中的伦理、隐私与合规。算法原理已经在“机器学习”课里讲过，本课只讲“怎么调用、结果怎么读、错了怎么查”。

全书 12 章、36 个实验，贯穿一个“食客说”城市美食点评平台的案例：订单、商家、用户和评论数据从第 2 章开始一路被采集、清洗、标注、分析、可视化，第 9 章训练评论情感分类模型，第 10 章给用户推荐餐厅，第 11 章监控上线后的模型，第 12 章做一次合规检查并完成综合项目。实验默认在普通笔记本电脑的 CPU 上用小数据完成；案例数据由编者按真实业务分布生成，随书提供，不含真实个人信息。

学完本课程，学生能够胜任人工智能数据服务岗位的基本工作：从多种来源采集业务数据，按规范清洗和标注，审核标注质量并写出审核报告，用统计和可视化方法分析数据并写出分析报告，调用模型完成预测和推荐，对上线的智能系统做日常维护并提出优化需求。

## 主要内容

- 数据分析与处理在人工智能项目中的位置；人工智能训练师、数据标注员等岗位与职业道德；数据的类型与格式；实验环境
- NumPy 数组运算与向量化；pandas 进阶：索引与筛选、合并与连接、分组聚合、透视表、窗口函数、时间序列处理、字符串处理、性能优化
- 数据采集：CSV、Excel、JSON 等文件，关系数据库（SQL 查询、SQLAlchemy），开放接口（requests、分页、限流），网页采集的基本原理与合规要求（详细内容归网络爬虫课）
- 数据清洗与整合：数据质量的六个维度、数据质量评估报告、缺失值、重复值、异常值、格式与单位不一致、文本与日期清洗、多表整合、清洗规范与可复用的清洗流水线
- 数据标注（一）：标注任务类型（分类、序列标注、目标框、分割、语音转写、大模型偏好标注），标注规范的编写，Label Studio 的部署与使用，标注数据的导出格式
- 数据标注（二）：标注质量的指标（准确率、一致率、Kappa 系数），抽检与验收，标注审核报告，模型预标注与主动学习，标注团队管理，合成数据
- 探索性分析与统计：描述统计、分布、相关分析、分组对比、抽样、置信区间、假设检验（t 检验、卡方检验）、A/B 测试
- 数据可视化与分析报告：图表选择、Matplotlib 与 seaborn、pyecharts 交互图表、Streamlit 数据看板、分析报告的结构与写法
- 建模应用：scikit-learn 流水线完成回归、分类、聚类并解读结果；调用预训练模型完成图像和文本任务；用大模型辅助数据分析及其风险
- 推荐系统：基于热门、基于内容、协同过滤、矩阵分解的直观理解，推荐效果评估，冷启动
- 智能系统运维与优化：模型部署到业务场景的方式、运行监控、日志分析、数据漂移、错误案例收集与分析、运维报告与优化需求
- 数据伦理、隐私与合规：个人信息保护法、数据安全法等要点，数据分类分级，脱敏与匿名化，算法偏见；综合项目

## 不涉及的内容

- 机器学习算法的原理推导、特征工程的系统讲解、模型调参，归“机器学习”课程（本课只做速记并链接）
- 神经网络、深度学习的原理和框架用法，归“机器学习”“神经网络与深度学习”“人工智能开发框架技术”课程；本课只调用现成的预训练模型
- 网页数据采集的完整技术（动态页面、反爬、分布式爬虫），归“网络爬虫技术”课程
- 海量数据的分布式处理（Hadoop、Spark），归“大数据技术处理技术”课程
- Python 语法、SQL 语法基础，归“Python 程序设计”“数据库基础与应用”课程（附录留速查）
- 人工智能数据处理工程师（中级）中“Python Web 全栈开发”模块（HTML、Django、Linux 部署），不在本专业任何一门课中，证书考点对照页标“本系列不覆盖”

## 学习目标

完成本课程后，学生能够：

### 记忆（Remember）

- 说出数据分析与处理在人工智能项目中的主要环节，以及人工智能训练师的职业功能和职业守则
- 列举常见的数据格式（CSV、Excel、JSON、Parquet、数据库表）和数据来源
- 复述数据质量的六个维度：完整性、准确性、一致性、唯一性、及时性、有效性
- 列举常见的数据标注任务类型和对应的标注工具
- 列出描述统计的常用指标和常见图表类型

### 理解（Understand）

- 解释向量化运算为什么比循环快，说明 pandas 分组聚合“拆分—应用—合并”的过程
- 说明不同类型缺失值、异常值的成因，以及删除、填充、保留各适用于什么情况
- 解释标注规范为什么要写清边界和特殊情况，说明 Kappa 系数比一致率更可靠的原因
- 解释 p 值和置信区间的含义，说明相关不等于因果
- 说明协同过滤“物以类聚、人以群分”的思路，以及冷启动问题的成因
- 解释数据漂移为什么会让上线的模型变差

### 应用（Apply）

- 使用 pandas 完成多表合并、分组聚合、透视、时间序列重采样等操作
- 从文件、数据库和开放接口采集数据并合并成一张分析表
- 按清洗规范用 pandas 实施清洗，并把清洗步骤封装成可复用的函数
- 部署 Label Studio，按规范完成文本分类、实体、图像目标框等标注任务并导出
- 计算标注一致率和 Kappa 系数，按抽检方案完成一次标注验收
- 使用 Matplotlib、seaborn、pyecharts 绘制图表，用 Streamlit 搭建简单的数据看板
- 使用 scikit-learn 流水线训练模型并解读评估结果，调用预训练模型完成预标注
- 实现基于热门、基于内容和基于物品的协同过滤推荐，并计算准确率、召回率等指标

### 分析（Analyze）

- 分析一份业务数据的质量问题，写出数据质量评估报告
- 通过分组对比、相关分析和假设检验找出影响业务指标的因素
- 分析标注不一致的原因，区分规范不清、标注员理解偏差和数据本身有歧义三种情况
- 分析上线模型的错误案例和监控数据，判断问题出在数据、模型还是业务变化

### 评价（Evaluate）

- 判断一张图表是否准确、清楚地表达了数据，指出误导性图表的问题
- 评价一批标注数据能否验收，并给出返工意见
- 评价一个 A/B 测试的结论是否可信
- 评估一个数据处理方案在个人信息保护和数据安全方面的风险

### 创造（Create）

- 为一个业务场景编写数据清洗规范和数据标注规范
- 撰写标注审核报告、数据分析报告和智能系统运维报告
- 综合项目：选择一个业务场景（如“食客说”评论分析、门店经营分析、客服工单分类），完成从数据采集、清洗、标注、分析、可视化到建模和合规检查的全过程，并提交项目报告
