## 教学说明

**学习目标**

1. 能说出人工智能项目中数据要经过的主要环节（记忆）；
2. 能判断一项具体工作属于哪个环节（理解）。

**画面与操作**

- 上方是 12 张工作卡片，下方是六个环节。用鼠标把卡片拖进环节；手机上先点卡片、再点环节。
- 点“检查答案”，放对的卡片变绿、放错的变红；“显示答案”直接给出参考分法。

**数据来源**：卡片内容来自本书“食客说”案例各章实验中的真实任务。

**课堂用法建议**

1. 上课开始时让学生先独立拖一遍，记下得分；学完全书最后一章再做一次，对比变化。
2. 讨论有争议的卡片，例如“抽查 200 条标注，计算标注准确率”算标注还是分析？引导学生理解“按主要目的来分”。
