# 交互动画

这些动画都是普通网页，不需要安装任何软件，也不需要联网调用接口，在电脑和手机浏览器上都能打开。每个动画都嵌在对应章节的正文里，也可以从这里单独打开，适合课堂演示。

<!-- sims:start -->
| 章 | 动画 | 你可以做什么 |
|---|---|---|
| 第 1 章 | [数据的旅程](data-journey/index.md) | 把 12 项日常数据工作拖到采集、清洗、标注与审核、分析、建模、上线运维六个环节里，检查自己是否分得清每个环节 |
| 第 2 章 | [四种连接方式](join-types/index.md) | 切换 inner、left、right、outer，看订单表合并商家表时哪些行留下、哪些格子变成空值 |
| 第 2 章 | [拆分—应用—合并](split-apply-combine/index.md) | 选择分组列和计算方式，一步一步看 groupby 怎样把 8 笔订单拆成小表、分别计算、再合成结果表 |
| 第 4 章 | [缺失值与异常值处理](missing-outliers/index.md) | 换缺失值的填充方法、调 3σ 和 IQR 的阈值，看分布、平均值和误判数量怎么变 |
| 第 4 章 | [正则表达式试验台](regex-lab/index.md) | 写一条正则表达式，实时标出评论里的手机号、广告、网页残留和重复标点，并预览替换效果 |
| 第 5 章 | [目标框标注与交并比](bbox-iou/index.md) | 在餐桌图片上拖框，实时显示你的框和参考框的交并比，以及是否达到 0.7 的验收标准 |
| 第 5 章 | [实体标注练习](entity-bio/index.md) | 在句子上点选菜品和店名，自动生成 BIO 序列，并和参考答案逐字比对 |
| 第 6 章 | [抽检验收模拟](acceptance-sampling/index.md) | 调整抽检条数和这批标注的真实错误率，看合格批被误退、不合格批被放过的概率 |
| 第 6 章 | [Kappa 计算器](kappa-calculator/index.md) | 修改两名标注员的混淆表，看一致率、碰巧一致率和 Kappa 怎样变化，理解为什么一致率高不等于标得一致 |
| 第 7 章 | [A/B 测试判读](ab-test/index.md) | 调整每组访客数和两组转化率，看差值的置信区间和 p 值，判断新版页面是否显著更好 |
| 第 7 章 | [抽样与置信区间](confidence-interval/index.md) | 反复从全部订单中抽样，看 100 个置信区间中有多少盖住了真实的平均送达时长，以及样本量和置信水平怎样影响区间宽度 |
| 第 8 章 | [图表选择与纠错](chart-chooser/index.md) | 选一个分析问题，看该用什么图；选一张误导性图表，逐项勾选改正方法，看图怎样变得诚实 |
