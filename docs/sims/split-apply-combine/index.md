## 教学说明

**学习目标**

1. 能用“拆分、应用、合并”三步说清 `groupby` 的计算过程（理解）；
2. 能根据问题选出分组列和计算方式，写出对应的一行代码（应用）。

**画面与操作**

- 上方选择“按城区 / 天气分组”和“求和 / 平均 / 计数 / 最大”。
- 每点一次“下一步”，前进一步：原表 → 拆成小表 → 每组算出一个数 → 合成结果表；下方同步显示对应的 pandas 代码。

**数据来源**：8 笔示例订单，取自“食客说”订单表的字段。

**课堂用法建议**

1. 先让学生用手算出“按城区求和”的结果，再用动画核对。
2. 改成“按天气计数”，提问：结果表有几行？由什么决定？（由分组列有几种取值决定。）
