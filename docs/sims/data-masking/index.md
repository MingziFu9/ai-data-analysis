## 教学说明

**学习目标**

1. 能说出掩码、哈希、泛化、扰动、删除五种脱敏方法的做法和效果（记忆）；
2. 能根据使用场景，按“最小必要”原则为每个字段选择脱敏方法（应用）。

**画面与操作**

- 先选一个使用场景，再在表格中为每个字段选择处理方法，下方显示分析可用性和泄露风险。
- 点“看推荐做法”可以看到编者给出的参考方案。

**数据来源**：记录取自随书 `users.csv`（编者生成的虚构数据）；可用性和风险的分数是为教学设计的示意。

**课堂用法建议**

1. 让学生分组，每组抽一个场景，先自己选，再和推荐做法对比，说明理由。
2. 讨论：“客服回访差评用户”为什么必须保留手机号？这时应该用什么其他措施保护它（权限控制、操作记录）？
