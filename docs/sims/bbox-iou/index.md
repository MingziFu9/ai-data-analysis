## 教学说明

**学习目标**

1. 能按“贴紧物体边缘”的要求画目标框（应用）；
2. 能说出交并比的计算方法，并用它判断一个框是否合格（理解）。

**画面与操作**

- 选择一个物体，在图上拖出一个框（手机上用手指拖）。黄色区域是两框的交集，右侧显示交并比和是否合格。
- 可以取消“显示参考框”，先凭感觉画，再打开参考框对照。

**数据来源**：图片为随书 `labs/data/images/table_03.jpg`，参考框来自 `images_boxes_参考.csv`。

**课堂用法建议**

1. 让学生故意把框画大一圈、画小一圈，体会交并比对“框得松”和“框得紧”都很敏感。
2. 比一比谁画的框交并比最高，再讨论：0.7 的标准对小物体（杯子）是不是更难达到？
