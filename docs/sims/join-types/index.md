## 教学说明

**学习目标**

1. 能说出 inner、left、right、outer 四种连接方式的区别（理解）；
2. 能根据统计目的选择合适的 `how` 参数（应用）。

**画面与操作**

- 点上方四个按钮切换连接方式。左表、右表中留下的行标绿，被丢掉的行划掉；结果表中对不上的格子显示为红色 NaN。

**数据来源**：4 笔示例订单和 3 家示例商家，故意设置了“订单找不到商家”（S09）和“商家没有订单”（S03）两种情况。

**课堂用法建议**

1. 切换前先让学生预测结果表有几行，再点按钮核对。
2. 提问：要统计“每家商家的订单数，包括没有订单的商家”，该选哪一种？（right 或把商家表放左边用 left。）
