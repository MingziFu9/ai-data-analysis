## 数据决定模型的上限
- **垃圾进，垃圾出**（Garbage In, Garbage Out）
- 一半“菜都凉了”标成好评 → 模型学错
- 漏采夜宵订单 → 模型没见过夜宵评论
- 这些问题改模型解决不了
- **以数据为中心的人工智能**

::: notes
大模型时代更是如此：各家大模型的差别，很大程度上来自训练数据的规模和质量。用来训练模型的数据叫训练数据。
:::

# 1.2 数据分析、数据处理与数据标注

## 三个容易混的词
| 词 | 回答的问题 | 主要产出 |
|---|---|---|
| 数据处理 | 数据能不能用？ | 干净、规整的数据表 |
| 数据标注 | 每条数据“是什么”？ | 带标签的训练数据 |
| 数据分析 | 数据说明了什么？ | 结论、图表和报告 |

::: notes
例子：合并三个系统导出的订单、统一“天河区”“天河”是数据处理；给评论标好评差评是数据标注；发现下雨天送达平均多 6 分钟、建议加补贴是数据分析。三者在工作中交织在一起，往往是同一个人、同一个团队做的。
:::

## 四类数据分析
- **描述性**：发生了什么？
- **诊断性**：为什么会这样？
- **预测性**：将来会怎样？
- **指导性**：应该怎么做？
- 越往后越难，也越有价值

::: notes
举“食客说”的例子：全年 56655 单、平均实付 133.2 元（描述）；7 月送达慢是因为雨天多（诊断）；预计这一单 32 分钟送达（预测）；雨天晚高峰缩小配送范围（指导）。用数据而不是凭感觉做决定，叫数据驱动。
:::

# 1.3 数据有哪些类型

## 按“有没有固定格式”分
| 类型 | 例子 | 怎么处理 |
|---|---|---|
| 结构化 | 订单表 | Excel、数据库、pandas |
| 半结构化 | 接口返回的 JSON、日志 | 先展平成表格 |
| 非结构化 | 评论、照片、录音 | 先标注或用模型提取 |

::: notes
企业里八成以上的数据是非结构化的。非结构化数据要么人工标注，要么用模型转换成结构化信息，这正是数据标注的价值。
:::

## 按“一列里装的是什么”分
- **数值型**：实付金额、送达时长，可以求平均
- **类别型**：城区、配送方式，只能数个数
- 有序类别：年龄段、1～5 星评分
- **时间序列**：每天的订单量，看趋势和周期
- 注意：**编号不是数值型**

::: notes
提问：用户编号 U00001 是数值型吗？手机号呢？都不是，它们是标识，求平均没有意义。证书考试常考这一点。
:::

## “食客说”的四张表
| 表 | 文件 | 行数 |
|---|---|---|
| 商家表 | shops.csv | 300 |
| 用户表 | users.csv | 5000 |
| 订单表 | orders.csv | 56655 |
| 评论表 | reviews.csv | 12000 |

::: notes
四张表靠编号连在一起：订单表的 user_id 对应用户表，shop_id 对应商家表，评论表的 order_id 对应订单表。数据由编者按真实平台的大致情况虚构生成，不对应真实的人和店。
:::

# 1.4 数据岗位与职业道德

## 人工智能训练师（四级）
| 职业功能 | 理论 | 技能 | 本书 |
|---|---|---|---|
| 数据采集和处理 | 20% | 30% | 第 2、3、4、7 章 |
| 数据标注 | 40% | 50% | 第 5、6 章 |
| 智能系统运维 | 20% | 20% | 第 9、11 章 |

::: notes
人工智能训练师是 2020 年发布的新职业，分五个等级。四级的三个职业功能中数据标注分量最重。另外理论考试还有 20% 是职业道德和基础知识。
:::

## 其他数据岗位
- **数据分析师**：招聘量最大，写分析报告
- **数据工程师**：搭建数据管道
- **算法工程师**：设计和训练模型
- 都依赖前面的人把数据准备好

## 数据工作的职业道德
- **遵纪守法**：个人信息保护法、数据安全法
- **保守秘密**：不外传、不拷贝到私人设备
- **实事求是**：不编造、不篡改、不隐瞒
- **严谨细致**：一时马虎，模型永远记错

::: notes
证书考点：训练师四级基础知识与职业道德。可以请学生讨论：把工作数据发到微信群里让同事帮忙看，有什么问题？第 12 章会系统讲法律法规。
:::

# 1.5 实验环境与读代码的方法

## 两种实验环境，任选一种
- **本机安装**：Anaconda 或 uv，推荐
- **云 Notebook**：飞桨 AI Studio、魔搭社区
- **Jupyter**：一格一格运行，Shift + Enter
- 卡住了：Kernel → Restart，从头运行

::: notes
线下课现场帮学生装环境。最常见的问题：没勾选加入 PATH、没激活虚拟环境、pip 太慢没加清华镜像。详细步骤见附录 C。
:::

## 读懂别人写的代码：四步
- **先看注释和输出**
- **找输入和输出**：读了什么、存了什么
- **一次只改一处**，看结果怎么变
- **加 print** 看中间结果

::: notes
本书的基础实验都是“读懂、运行、修改”，不要求从零写。演示实验 1-2 的代码：先把注释连起来读一遍。
:::

## 报错不可怕：先看最后一行
| 报错 | 最常见的原因 |
|---|---|
| ModuleNotFoundError | 库没装或装错环境 |
| FileNotFoundError | 没在实验文件夹里运行 |
| KeyError | 列名写错，多了空格 |
| SyntaxError | 用了中文标点 |
| UnicodeDecodeError | 编码不对（第 3 章） |

::: notes
现场故意制造一个 FileNotFoundError（把 shops.csv 写成 shop.csv），带学生读报错。
:::
