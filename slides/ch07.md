# 7.1 描述统计

## 用几个数字概括一列数
- **集中趋势**：平均值、中位数、众数
- **离散程度**：标准差、分位数
- 实付金额：平均 **133.2** 元，中位数 **93.6** 元
- 大单把平均值“拉高”了
- **右偏、长尾**：报告时两个都给

# 7.2 探索性分析的套路

## 实验 7-1 的五条发现
- 实付金额右偏：平均 133.2，中位数 93.6
- 按中位数：快餐 40.9 元，日料 245.9 元
- 配送距离与送达时长相关系数 **0.66**
- 雨天送达多约 6 分钟，商家自送多 4～5 分钟
- 就餐人数与实付金额相关系数 0.61

::: notes
套路：单变量（分布）→ 双变量（关系）→ 分组对比，把发现写成一句话加一个数字。
:::

# 7.3 相关分析

## 相关系数与“相关不等于因果”
- 接近 1 正相关，接近 −1 负相关，接近 0 无直线关系
- 相关不等于因果，三种情况：
- **第三个因素**：冰淇淋与溺水
- **因果倒置**：老顾客本来就更常拿到券
- **纯属巧合**：变量多了总有碰巧相关的

## 辛普森悖论
- 合起来看：新版更差
- 分开看：老城区、新城区**都是新版更好**
- 原因：新版的访客大多来自转化率低的新城区
- 分组不随机，比例不同，合并后结论反了
- 解决：**随机分组**的 A/B 测试

::: notes
回答小陈：实验 7-3 中按城区类型分开，新版在两类城区都更好（+1.70%、+0.90%）。合起来看新版更差，是因为两组访客的城区构成不同。
:::

# 7.4 总体、样本与置信区间

## 用样本推断总体
- 简单随机抽样、分层抽样
- **方便抽样**往往有偏
- **置信区间**：估计的范围 + 把握
- 例：平均送达时长 95% 置信区间 [26.8, 29.3]
- 样本越大，区间越窄

## 动手试：置信区间
!sim confidence-interval
- 反复抽样，看区间有多少次盖住真值
- 改变样本量，看区间的宽窄

# 7.5 假设检验

## 检验的思路和 p 值
- 先假设**没有差别**（原假设）
- 算“碰巧出现这么大差别”的概率：**p 值**
- p < 0.05：拒绝原假设，差别显著
- **t 检验**：两组平均值；**卡方检验**：两个类别变量
- 商家自送 31.3 分钟 vs 平台专送 26.9 分钟，p < 0.001

::: notes
回答小李：卡方检验 p = 0.279，没有足够证据表明用券与好评有关，“少发券”的建议站不住。证书考点：Python 技术应用工程师（中级）数据分析，要会用 scipy 做 t 检验和卡方检验并写出结论。
:::

## 读检验结果的常见误读
| 误读 | 正确的说法 |
|---|---|
| p = 0.03，原假设成立概率 3% | 假如原假设成立，出现这样数据的概率 |
| p = 0.28，两组没有差别 | 没有足够证据表明有差别 |
| p < 0.001，差别很大 | 只说明很可能是真的，大小另看 |
| 做 20 次，有一次显著 | 碰巧也会有一次 |

::: notes
每组只抽 30 单时，平均 29.0 对 28.5，p = 0.811，不显著：样本少时，真有差别也可能检测不出来。
:::

# 7.6 A/B 测试

## A/B 测试：确认因果
- 事先定好：**目标指标、分组、样本量、判断标准**
- 随机分组，每个访客始终看同一版本
- 至少覆盖一个完整的星期
- **不要一边测一边看**，看到显著就停

## 判读 A/B 测试的结果
| 版本 | 访客数 | 下单数 | 转化率 |
|---|---|---|---|
| A 旧版 | 10106 | 749 | 7.41% |
| B 新版 | 9894 | 860 | 8.69% |

- B − A = +1.28%，95% 置信区间 [+0.53%, +2.04%]

::: notes
先检查分组是否成功：两组老城区访客比例 50.3% 和 50.1%，相近。结论写法：提高了多少、置信区间、p 值，再看是否达到“值得上线”的最小提升。
:::
