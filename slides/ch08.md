# 8.1 图表选择

## 先问“想回答什么问题”
| 问题 | 例子 | 首选图表 |
|---|---|---|
| 比较 | 哪个菜系订单最多？ | 条形图 |
| 趋势 | 交易额每月怎么变？ | 折线图 |
| 构成 | 两种配送方式各占多少？ | 饼图（2～5 类） |
| 分布 | 订单金额一般多少？ | 直方图、箱线图 |
| 关系 | 送得越远越慢吗？ | 散点图 |
| 地理 | 哪个城区交易额最高？ | 地图、条形图 |

::: notes
三条原则：比较大小用长度（人眼比较长度最准）；时间放横轴从左到右；一张图只说一件事。
:::

# 8.4 误导性图表：图会“说谎”

## 四种误导性图表
![误导性图表及改正](img/lab8_1_misleading.png)

::: notes
左上：条形图纵轴截断，黄埔 61.1%、天河 64.8%、越秀 71.7% 的差别被放大；改正：从 0 开始。右上：饼图切太多块。左下：双纵轴让两条线看起来高度相关（实际相关系数只有 0.3）。右下：只截 8 月到 9 月，“下降 10.8%”，看全年其实是季节波动。
:::

## 怎样避免误导
- 条形图纵轴**从 0 开始**
- 饼图**不超过 5 块**，其余合并为“其他”
- **慎用双纵轴**，改成上下两张图
- 时间范围要**完整**，同比、环比都看
- 不用三维效果

# 8.6 数据分析报告

## 报告的结构
- **标题和摘要**：3～5 句，老板可能只读这一段
- 背景与问题、数据与方法
- **分析发现**：一句结论 + 一张图 + 数字
- **建议**：谁来做、预期效果
- 局限与下一步

## 用数据讲故事
- **结论先行**：小节标题就是结论
- **一条发现配一张图**
- **有对比才有意义**：比上季度、比别的区
- **区分事实和推测**
- **建议要能执行**

::: notes
报告示例中的一条发现：送达超过 40 分钟的订单占 7.7%，好评率 55.0%，其他订单 63.9%，卡方检验 p < 0.001。建议要具体：雨季午晚高峰给骑手加补贴、缩小配送范围。模板见附录 E.7。
:::
