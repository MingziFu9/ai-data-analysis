# 6.1 怎样衡量标注质量

## 三种衡量方法
- **标注准确率**：和**金标准**比
- **一致率**：两个人标得一样的比例
- **Kappa 系数**：扣除“碰巧一致”后的一致程度
- **交并比**：两个框重叠部分 ÷ 合起来的部分
- 没有标准答案时，看一致性

## Kappa 系数
- Kappa =（实际一致率 − 碰巧一致率）÷（1 − 碰巧一致率）
- 例：一致率 80%、碰巧 50% → Kappa = 0.6
- 0.81～1.00 几乎完全一致
- 0.61～0.80 较强，0.41～0.60 中等
- 实验 6-1：A 与 B 一致率 80.7%，Kappa 0.686

::: notes
举“偷懒”的例子：两人各 94% 标正面，一致率 88%，碰巧一致率却有 88.5%，Kappa 约 −0.05，还不如随便乱标。三人以上用 Fleiss' Kappa，实验 6-1 三人是 0.619。证书考点：Kappa 的计算和取值含义。
:::

# 6.2 抽检验收

## 抽检方案
- 每批**按标注员分层**抽 10%
- 准确率 ≥ 95% 判合格
- 不合格的加抽 20%，合并计算
- 仍不合格：该标注员这批全部返工
- 两种误判：合格的被误退、不合格的被放过

::: notes
为什么要加抽：抽得越少误差越大。真实 96.5% 的人抽 60 条错 4 条就会被误判。
:::

:::

# 6.3 审核流程与审核报告

## 多级审核流程
!mermaid 1

::: notes
初标（自查）→ 互检 → 质检（按抽检方案）→ 验收（需求方再抽检）。每一级发现的问题都要记录，用于计算质量指标、修订规范、培训标注员。
:::

## 标注审核报告
- **基本情况**：批次、数据量、标注员、规范版本
- **抽检方案**：方法、比例、合格标准
- **抽检结果**：整批和每人的准确率
- **错误分析**：正面误标为中性最多
- **处理意见**：返工、修订规范、培训

::: notes
结论要有数字支撑：“W03 偏低”不如“W03 两次抽检共 115 条，准确率 85.2%，低于 95% 的验收标准”。模板见附录 E.5。证书考点：训练师四级标注审核。
:::

# 6.4 多人标注与噪声标签

## 多数投票与 cleanlab
- 三人独立标同一条，**少数服从多数**
- 实验 6-1：多数投票准确率 **96.7%**
- **噪声标签**：训练数据中标错的标签
- cleanlab 找出可疑标签 116 条，真错的 111 条
- 最终由**人**来判断

# 6.5 提效：预标注与主动学习

## 预标注与主动学习
![随机挑选与主动学习](img/lab6_3_active.png)
- **预标注**：模型先标，人来改
- **主动学习**：先标模型最拿不准的
- 标到 800 条后，主动学习明显领先

::: notes
预标注的风险：标注员不看就点确认。所以预标注的数据照样要抽检。主动学习在模型太弱时反而不如随机，因为它拿不准的往往是特别难、特别怪的数据。
:::

# 6.6～6.7 团队管理与合成数据

## 标注团队管理
- 培训和考核：先考试，后上岗
- 进度与成本：每人每天的工作量
