# 2.2 从 Excel 到 pandas

## DataFrame 就是一张表
| Excel | pandas | 例子 |
|---|---|---|
| 一个工作表 | DataFrame | orders |
| 一列 | Series | orders["实付金额"] |
| 行号 | 索引 | 0, 1, 2… |
| 列标题 | 列名 | "实付金额" |
| 单元格格式 | 数据类型 | float64、str |

## 读表和看表
```python
import pandas as pd
orders = pd.read_csv("../data/orders.csv")
print(orders.shape)        # (56655, 12)
print(orders.head())       # 前 5 行
print(orders.dtypes)       # 每列的类型
print(orders.describe())   # 数值列的描述统计
```

::: notes
拿到一张表，先看几行几列、前几行、每列类型、描述统计，这四步相当于在 Excel 里“打开文件、拖一拖滚动条”。describe 一行就算出了计数、平均、标准差、最小、四分位数、最大。
:::

# 2.3 选行选列、筛选、排序、新增列

## 条件筛选
```python
rain = orders[orders["天气"] == "雨"]
slow = orders[(orders["天气"] == "雨") & (orders["送达时长"] > 45)]
two = orders[orders["配送方式"].isin(["平台专送"])]
```
- 等于用 `==`，并且 `&`，或者 `|`
- 每个条件**都要加括号**

::: notes
实验 2-1：雨天且超过 45 分钟的订单有 804 单。最常见的错误：少了括号，或者用 and 代替 &。
:::

## 排序、新增列、loc 与 iloc
- 排序：`sort_values("实付金额", ascending=False)`
- 新增列：`df["人均实付"] = df["实付金额"] / df["就餐人数"]`
- **整列一起算**，不用往下拖
- `loc` 按标签选，`iloc` 按位置选

## Excel 与 pandas 对照
| 想做的事 | pandas |
|---|---|
| 打开文件 | pd.read_csv() |
| 几行几列 | df.shape |
| 求平均 | df["列"].mean() |
| 筛选 | df[条件] |
| 排序 | df.sort_values() |
| 另存为 | df.to_csv(…, encoding="utf-8-sig") |

::: notes
这张表建议打印出来贴在电脑旁。保存时写 utf-8-sig，Excel 打开不乱码（第 3 章讲原因）。
:::

## groupby + agg
```python
df.groupby("城区").agg(
    订单数=("order_id", "count"),
    销售额=("实付金额", "sum"),
    客单价=("实付金额", "mean"),
).round(1).sort_values("销售额", ascending=False)
```
- 天河 11063 单，销售额 150.7 万，客单价 136.2

::: notes
证书考点：Python 技术应用工程师（中级）数据处理，常考 groupby 的写法和 agg 的命名方式。透视表 pivot_table(index=, columns=, values=, aggfunc=) 和 Excel 的数据透视表一一对应，注意 aggfunc 默认是平均值。
:::

# 2.5 两张表合并：pandas 版的 VLOOKUP

## merge 就是 VLOOKUP
```python
df = orders.merge(shops, on="shop_id", how="left")
print("合并前", orders.shape, "合并后", df.shape)
# 合并前 (56655, 12) 合并后 (56655, 14)
```
- 按共同的编号列把两张表连起来
- 合并后**一定核对行数**

## 四种连接方式
| how | 留下哪些行 |
|---|---|
| inner | 两边都有的 |
| left | 左表的全部（最常用） |
| right | 右表的全部 |
| outer | 两边的全部 |

::: notes
用动画演示：S3 只在左表，S4 只在右表，看不同连接方式下谁留下、哪些格子变成空值。
:::

# 2.6 日期和时间

## 文字 → 日期时间
- `pd.to_datetime(orders["下单时间"])`
- `.dt.month` 月份，`.dt.hour` 小时
- `.dt.day_of_week` 星期几（0 是周一）
- `resample("D")` 按天汇总，`"MS"` 按月
- 2 月 2887 单最少，12 月 5965 单最多

::: notes
读进来的时间是文字，先转换才能取月份、做加减。实验 2-3 就是用小时和星期找订单高峰。
:::

# 2.7 NumPy 一瞥

## 向量化：快几十倍
- 循环逐个算：23.3 毫秒
- 整列一起算：0.36 毫秒
- **能整列算，就不写循环**
- pandas 的底层就是 NumPy 数组

::: notes
你电脑上的时间会不同，但差距大致相同。原因是循环每算一个数都要经过 Python 解释器，向量化交给底层 C 代码一次算完。
:::
