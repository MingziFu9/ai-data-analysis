## 情景导入：模型没变，效果变了
- 3 月初，情感模型上线，头一个月顺利
- 4 月中旬：夸我们的被判成中评，差评没推过来
- 技术组：最近接口经常超时
- 模型文件**一个字节都没变**
- 是模型、数据还是系统的问题？

# 11.1 智能系统怎样上线

## 两种上线方式与灰度发布
- **批量预测**：定时把一批数据全部预测，如每周用户分群
- **在线服务**：来一个请求马上返回，如新评论判情感
- 每个模型都要有**版本号**
- **灰度发布**：10% → 50% → 100%
- 有问题能马上**回滚**

# 11.2 运行日志与监控指标

## 三类监控指标
| 类别 | 回答什么问题 | 常用指标 |
|---|---|---|
| 系统 | 跑得稳不稳、快不快 | 调用量、P95 延迟、错误率 |
| 模型 | 输入输出有没有异常 | 各类预测比例、低把握比例 |
| 业务 | 对业务有没有帮助 | 抽检准确率、差评处理时间 |

::: notes
运行日志记录每次调用的时间、耗时、状态码、预测结果。P95 延迟：100 个请求里第 95 慢的那个，比平均延迟更能反映用户的感受。
:::

# 11.3 数据漂移与概念漂移

## 模型没变，为什么效果会变
- **数据漂移**：输入的分布变了
- 新流行语“绝绝子”“yyds”，长评返券活动
- **概念漂移**：输入和标签的关系变了
- “是预制菜吧”从中性变成不满
- 概念漂移要**修改规范、重新标注**

## 用 PSI 衡量分布变化
- 按基准期分 10 个箱，比较各箱占比的变化
- **< 0.1** 稳定；**0.1～0.25** 需要关注；**> 0.25** 排查
- 评论长度 PSI：第 5、6 周超过 0.1
- 平均长度 19.2 → 21.4 字
- PSI 只说明分布变了，影响多大要**抽检**

::: notes
证书考点：训练师四级智能系统运维，常考 PSI 的判断标准和数据漂移、概念漂移的区别。
:::

## 动手试：数据漂移与 PSI
!sim drift-psi
- 给评论加上“新说法”，看分布和 PSI
- PSI 超过 0.1 时亮黄灯

## 找出新说法
- 比较上线前后**新出现的两字组合**
- 五种新说法：yyds、绝绝子、是预制菜吧、纯纯冤种、拔草了
- 第 5 周起约 **30%** 的评论里有
- 不含新说法：准确率 96.4%
- 含新说法：准确率 **93.5%**

# 11.4 坏案例：收集、归类、归因

## 坏案例从哪里来、怎么归因
| 归因 | 典型表现 | 怎么改进 |
|---|---|---|
| 数据问题 | 乱码、截断、标签标错 | 修数据、修标签 |
| 模型问题 | 好坏都有的评论判不准 | 换特征、换模型 |
| 业务变化 | 新说法、新菜系、新业务 | 补标、更新规范 |

::: notes
坏案例来源：用户和一线反馈、定期抽检、监控异常（低把握、和评分矛盾）。实验 11-3：抽检 6000 条中 267 条错误，按规则预归因后再人工复核。
:::

# 11.5 人工反馈与数据闭环

## 数据闭环
!mermaid 1

::: notes
监控 → 坏案例 → 归因 → 补标 → 重训 → 评估 → 灰度上线，再回到监控。实验 11-3：补标 1000 条后重训，整体准确率 95.5% → 97.4%，含新说法的评论 93.3% → 97.0%。比较新旧模型要用同一批、都没参与训练的数据。
:::

## 人在闭环中的作用
- 最费人力的是**补标**
- 预标注、主动学习都能用上（第 6 章）
- 关键在流程：谁收集、多久归因一次
- 补标多少、谁审核、谁批准上线
- **写成制度**，否则闭环会断

# 11.6 运维报告与优化需求
